# Automated Model Rocket Launch & Recovery System

## Overview
![MODEL ROCKET IMAGE.jpg…]()


This project focuses on the design and development of an **automated model rocket launch and recovery system**, integrating an electrical launch mechanism, guided launch stand, solid-propellant motor, aerodynamic rocket structure, and parachute-based recovery system.

The system was developed as an integrated platform covering the complete sequence from **launch initiation to rocket recovery**.

## Key Features

- ⚡ Electrical launch mechanism
- 🚀 Single-stage model rocket
- 🧭 Guided launch platform
- 🔥 Solid-propellant motor
- 🪂 Parachute recovery system
- 📐 OpenRocket aerodynamic analysis
- 🔩 Custom mechanical launch structure

## Launch System

The launch system consists of a custom-built vertical launch stand and an **electrical launch control mechanism**. The rocket is supported and guided during the initial launch phase, while the electrical control system provides controlled launch initiation.

## Propulsion

The experimental rocket uses a sugar-based solid-propellant formulation consisting of:

- Sugar — 60%
- Potassium Nitrate — 38%
- Sulfur — 2%

The propulsion system is treated as an experimental component of the project. Motor performance is not inferred from propellant composition alone.

## Recovery System

A parachute-based recovery system is incorporated to reduce the rocket's landing velocity.

The system includes:

- 30 cm ripstop nylon parachute
- Shock cord
- Shroud lines
- Recovery compartment
- Protective wadding

## OpenRocket Simulation

The rocket was modeled in **OpenRocket** to evaluate aerodynamic stability and flight characteristics.

The reference simulation configuration reports:

| Parameter | Value |
|---|---:|
| Mass with reference motor | 204 g |
| CG | 50.7 cm |
| CP | 61.3 cm |
| Stability | 4.22 cal |
| Reference Apogee | 568 m |
| Maximum Velocity | 196 m/s |
| Time to Apogee | 7.17 s |

> **Note:** The above flight-performance values are from the reference **F41W motor simulation** and are not measured performance values for the experimental propellant.
